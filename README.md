# Website code for https://libeks.github.io

See the website [here](https://libeks.github.io)!

## Instructions

- Run dev server:
  `npm run dev`
- Run tests:
  `npm run tests`
- Generate favicon.ico from svg:
  `/Applications/Inkscape.app/Contents/MacOS/inkscape -w 96 -h 96 favicon_flipped.svg -o favicon_flipped.png`
